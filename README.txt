FLEX ROLLING 7 DAYS — Android / Samsung PWA

1. Giải nén ZIP.
2. Đăng toàn bộ file trong thư mục lên một website HTTPS (ví dụ GitHub Pages hoặc Netlify).
3. Mở đường dẫn HTTPS bằng Chrome trên Android hoặc Samsung Internet.
4. Menu > Install app / Add to Home screen.
5. Mở app một lần khi có mạng để cache; sau đó dùng offline.

Không thể cài PWA hoàn chỉnh chỉ bằng cách mở file HTML từ Downloads.
Dữ liệu lưu trên từng trình duyệt/thiết bị; dùng Export JSON để sao lưu.
